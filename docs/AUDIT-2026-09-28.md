# Audit kode QA RAG — 28 September 2026

## Kesimpulan

Sistem belum layak dinyatakan bebas error atau siap produksi penuh.
Audit ini menemukan kegagalan layanan model nyata, beberapa cacat kode, dan
kelemahan kualitas jawaban yang tidak terlihat pada pengujian simulasi sebelumnya.
Arsitektur dipertahankan: pertanyaan asli + satu perluasan, dense/BM25, RRF,
reranking 20 kandidat, maksimal lima sumber, dan generasi jawaban bersitasi.
Threshold reranker tetap -1 dalam skala logit mentah.

## Cakupan

Peninjauan kode aktif app/, web/, deploy/, tools/, smoke_test.py, run.ps1,
konfigurasi dependensi, serta pengujian. Tidak mengubah notebook atau proyek lain.
Model/indeks biner tidak dilatih ulang. Backup sebelumnya dipertahankan.

## Hasil inference nyata

Empat model terdaftar berhasil merespons prompt sangat pendek secara terpisah.
Itu tidak cukup sebagai bukti kestabilan pipeline lengkap.

Torch lokal adalah versi CPU; karena itu audit tidak menyimpulkan bahwa embedding
sebelumnya memakai VRAM. GPU tersedia adalah RTX 3050 Laptop 4 GiB. Pada percobaan
lengkap, layanan model mengembalikan kegagalan alokasi CUDA, termasuk buffer sekitar
1,65 GB. Beberapa percobaan memuat seluruh komponen juga mengalami kegagalan
alokasi memori proses. Kondisi RAM berubah selama pengujian.

Pengujian ulang GPU melalui API: dua JSON dan satu SSE gagal dengan model_memory.
HTTP 200 pada SSE hanya menandakan stream terbuka: tahap terakhirnya error, bukan done.

## Pengaturan memori

- OLLAMA_NUM_BATCH=128: batas batch prompt, tidak mengurangi panjang konteks.
- OLLAMA_NUM_CTX=8192 tetap.
- OLLAMA_NUM_GPU=-1: biarkan Ollama menentukan perangkat.
- OLLAMA_NUM_GPU=0: jalankan model jawaban/ekspansi di CPU; terbukti bisa berjalan pada dua kasus, tetapi lebih lambat.
- Belum mengaktifkan perpindahan CPU otomatis atau retry tersembunyi.
- Pilihan GPU eksplisit pada embedding/reranker tetap dihormati; default GPU kecil
  memakai CPU. Pada instalasi Torch CPU ini, kebijakan tersebut tidak mengubah perangkat yang sudah digunakan.

Ukuran batch saja terbukti belum mengatasi kegagalan GPU pada pengujian ini.
Dukungan opsi runner num_ctx, num_batch, num_gpu dirujuk dari kode resmi Ollama:
[opsi runner Ollama](https://github.com/ollama/ollama/blob/main/api/types.go).
Tidak ada restart paksa layanan pengguna, penghapusan model, atau perubahan driver.

## Risiko yang masih terbuka

1. Kualitas faktual: tahun data, wilayah, populasi, satuan, dan target/realisasi belum
   diperiksa secara semantik menyeluruh. Angka yang kebetulan muncul di sumber dapat
   salah dikaitkan. Jawaban needs_review tetap ditampilkan sesuai kebutuhan pengguna.
2. Ekspansi: satu kekeliruan IPM sudah ditangani, tetapi drift wilayah/topik dan
   sinonim yang salah memerlukan kumpulan evaluasi berlabel.
3. Retrieval: threshold belum dikalibrasi; beberapa chunk dapat berasal dari publikasi
   sama. Skor tinggi tidak menjamin jawaban atas pertanyaan.
4. Estimasi konteks masih berdasarkan byte secara konservatif; jumlah sumber bisa
   kurang dari lima. Tokenizer tepat model belum diintegrasikan.
5. Kapasitas host/GPU dan uji beban bersamaan belum memenuhi pembuktian produksi.
6. Pembatalan menunggu batas operasi / timeout untuk komputasi atau I/O yang sudah berjalan.
7. Visual browser nyata, deployment HTTPS publik, autentikasi operasional, rate limiting
   lintas proses, dan evaluasi akurasi per skenario belum dituntaskan pada audit ini.
8. Tidak ada klaim bahwa notebook performa sudah menilai seluruh risiko kualitas ini.

## Validasi regresi

Tes mencakup error HTTP/NDJSON, kehabisan memori, timeout, cache setelah pulih,
fit konteks, sitasi gabungan, kelompok penduduk, URL rusak, pengosongan non-RAG,
error API aman, penghentian/restart executor, antrean, dan pilihan perangkat.
Frontend diuji dengan simulasi DOM/SSE; tidak diklaim sebagai pengujian visual browser nyata.

Hasil akhir: 57 tes backend lulus; kedua rangkaian frontend lulus; pemeriksaan sintaks JavaScript dan diff lulus; pip check melaporkan tidak ada dependensi rusak. Traceback simulated pada unittest adalah skenario error yang disengaja, bukan kegagalan tes.
